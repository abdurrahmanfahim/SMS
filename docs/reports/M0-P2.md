## Decisions others depend on
- **`private` schema is off-limits to product tables** (per the baseline migration's own comment and ADR/runbook references) — any future migration needs a table it wants hidden from the API to either live in `private` (infra only) or use RLS in `public` (the normal case) — never assume a product table can go in `private` "because it's simpler."
- **Migration naming and forward-only rule** (ADR 0003) — every future schema-touching task follows `YYYYMMDDHHMM_<ws>_<desc>.sql` and never edits a shipped migration.
- **Three fully separate environments, no shared project** (ADR 0002) — a future deploy/production task should not propose a shared-project-with-a-flag alternative without revisiting this ADR explicitly.
- **`db:*` script names** (`db:start`, `db:stop`, `db:reset`, `db:test`, `db:types`, `db:diff`, `db:push:staging`) are now a contract, same status as `M0-P1`'s root scripts.
