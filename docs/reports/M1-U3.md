## Deviations and assumptions

1. **Font substitution.** `design-system.md` §1 specifies Hind Siliguri (primary) + Noto Sans Bengali (fallback). Hind Siliguri is not present as an asset anywhere in this repo. Since prototypes must work offline once loaded (no external font CDN, matching the project's no-external-call pattern), I self-hosted the one Bangla font that _is_ already in the repo (`spikes/pdf/layouts/fonts/NotoSansBengali-{Regular,Bold}.woff2`) as the sole prototype typeface. This is prototype-only and does not set a production precedent.
2. **40-student rosters are generated, not hand-typed.** `bnRoster(n)` in `shared/app.js` builds realistic Bangla names from a first/last-name pool rather than 40 manually written names, so the hassle-target tasks (§5 of `mobile-complete.md`) test against a real 40-student class size. The design-system.md long-name and triple-conjunct test strings are force-inserted at fixed positions so every roster exercises both.
3. **Sync/offline is simulated by a facilitator toggle**, not real network interception (`navigator.onLine`/service worker), since these are static files with no backend to actually go offline from. A fixed corner button lets a moderator show the offline/pending/synced states on demand during a test session.
4. **The attendance status control is 44px tall but narrower than 44px wide** (`.seg button`, `min-width: 32px`) — four toggle targets (present/absent/late/leave) plus a name column do not fit at full 44×44px each on a 360px screen. Flagged under Requests below rather than silently resolved.
5. **Verification tooling was installed with `npm install --no-save`** (not committed to `package.json`/`pnpm-lock.yaml`) since `@playwright/test`, `@axe-core/playwright`, `serve`, and `jsdom` are throwaway local verification aids, not something the running prototypes depend on. `node_modules/` is already gitignored.
6. **Status is Partial, not Blocked**, because two of six acceptance criteria are unmet but the largest coherent subset (all five prototypes, both research documents, and everything that could be automatically verified) is genuinely done — per `AGENT-PROTOCOL.md` §5's definition of Partial.
