# M1-L1 — Exam and result engine spec and golden-test plan

| Workstream | Size | Milestone | Wave | Status |
|---|---|---|---|---|
| WS-L (Leader) | M | M1 | 0 | DONE |

**Depends on:** M0-L1 (soft: M0-O1) · **Blocks:** M2-D1

## Goal
Define the result rules precisely enough that the domain engine (M2-D1) and the exam UI (M2-E1 to E4) can be built in parallel and tested against real marksheets.

## Deliverables
- `docs/spec/results-engine.md`: subject and component marks, pass rules, grade scheme config schema, GPA-style rules, optional (4th) subject rule, absent and exempt handling, totals, averages, rounding, merit ranking and tie-breaks, publish snapshot format
- Golden-test plan: how real samples from M0-O1 become fixtures, and the fixture file format
- Config JSON schema for `grade_schemes.config` and its presets
