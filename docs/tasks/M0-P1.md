## 3. Project context (so you are never lost)
- Product: a Bangla-first school management system for schools, madrasas and coaching centres in Bangladesh, built so an institution can run everything on a phone. It is a separate paid product; Munshi is a different, free, single-user app.
- Stack: TypeScript (strict), React 19, Vite, Tailwind, shadcn/Radix, Supabase (Postgres, RLS, Edge Functions), pnpm monorepo, Netlify.
- Layout: `apps/web`, `packages/{domain,db,ui,config}`, `supabase/`, `e2e/`, `docs/`.
- Tenancy: one database; every tenant row has `institution_id`; isolation is enforced by Postgres RLS, never by app code.
- Roles: platform owner, institution admin, teacher, accountant, guardian, student.
- Phone-complete: every task must work on a 360 px phone with touch only (Android first, iPhone second).
- Numbers: money in integer poisha; marks in integer hundredths inside calculations; never floating point.
- Language: Bangla first, English second; all user-visible text goes through i18n keys.
- Quality bar: WCAG 2.2 AA, `docs/spec/ux-standard.md`, and the Definition of Done in README section 9.

**Decisions in force for this task (do not reopen them):**
- D-03 — Language and frontend: TypeScript (strict); React 19 + Vite + Tailwind + shadcn/Radix (same family as Munshi); pnpm monorepo; Netlify hosting unless `M0-P3` finds a reason to change
- D-13 — Repository: New private repo; Munshi repo untouched

### 5.5 Common mistakes for this kind of work
- Every table needs RLS enabled, policies, and tests for: allowed role passes, other role fails, other tenant fails.
- Use composite tenant foreign keys `(institution_id, parent_id)`; never trust `institution_id` sent by a client.
- Migrations are forward-only and named `YYYYMMDDHHMM_plat_<desc>.sql`; never edit an applied one. Regenerate and commit `packages/db/src/types.ts`.
- `SECURITY DEFINER` functions must set `search_path` to empty and check the caller's role and tenant inside.
- The service-role key exists only in server code and CI secrets. Never in the client bundle, logs or docs.
