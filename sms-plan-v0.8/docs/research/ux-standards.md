# International UI/UX standards relevant to SMS

Access date: 2026-09-20. **There is no single "international UI/UX standard for school management systems".** What exists is general: ISO standards for usability and human-centred design, W3C accessibility guidelines, widely used design heuristics, platform guidelines and performance targets. We adopt them as below. Sources are listed with each item; secondary sources are marked.

## What this means in practice

1. Process follows ISO 9241-210; quality is measured with the ISO 9241-11 triple.
2. Accessibility target is WCAG 2.2 AA. Four of its new rules change our designs directly: no drag-only reordering (2.5.7), sticky bars must not hide the focused element (2.4.11; matters for marks grids with sticky headers), sign-in must not need puzzles or memory tests and must allow paste (3.3.8), and do not ask for the same information twice in one flow (3.3.7). Add a help entry in the same place on every page (3.2.6).
3. Nielsen's list is the review checklist; the ISO 9241-110 principles are a second lens.
4. Performance is judged on real phones with the Core Web Vitals targets.
5. Bangla text is tested with real conjuncts and long names, not lorem ipsum.

## Limits of this research

Several items were read through secondary sources (blogs, vendor pages, course notes) because the primary standards are paywalled (ISO) or were not opened directly. Verify against the primary text before quoting in contracts or sales material.

## Mobile capability notes (added for decision D-16)

Access date: 2026-09-20.

- Device mix: Android was 91.2% and iOS 8.73% of mobile use in Bangladesh in August 2026 (StatCounter, https://gs.statcounter.com/os-market-share/mobile-operating-system/bangladesh). Test Android first.
- Sharing files from a web app: feature-detect with `navigator.canShare({ files })`; PDFs and some other file types are allowed (web.dev, https://web.dev/articles/web-share).
- iPhone web apps: Web Push only for apps installed to the home screen (iOS 16.4 and later); Background Sync not supported (https://firt.dev/notes/pwa-ios/). Storage persistence limits are discussed in a MagicBell guide (secondary source, https://www.magicbell.com/blog/pwa-ios-limitations-safari-support-complete-guide).
- On-screen keyboard: default behaviour resizes only the visual viewport; `interactive-widget` in the viewport meta changes it (MDN, https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Viewport_meta_element; explanation at https://htmhell.dev/adventcalendar/2024/4/). A forum post reports Edge ignoring it (anecdotal, https://learn.microsoft.com/en-us/answers/a/1831159); verify on real devices.
