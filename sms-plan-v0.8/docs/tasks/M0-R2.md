## 3. Project context (so you are never lost)

- Layout: `apps/web`, `packages/{domain,db,ui,config}`, `supabase/`, `e2e/`, `docs/`.
- Tenancy: one database; every tenant row has `institution_id`; isolation is enforced by Postgres RLS, never by app code.
- Roles: platform owner, institution admin, teacher, accountant, guardian, student.
- Phone-complete: every task must work on a 360 px phone with touch only (Android first, iPhone second).
- Numbers: money in integer poisha; marks in integer hundredths inside calculations; never floating point.
- Language: Bangla first, English second; all user-visible text goes through i18n keys.
- Quality bar: WCAG 2.2 AA, `docs/spec/ux-standard.md`, and the Definition of Done in README section 9.

**Step 1.** `docs/research/providers.md`: 4+ text-alert options in Bangladesh (aggregators and direct): price per segment (masking and non-masking), Unicode handling, API style, delivery reports and webhooks, sender-ID or masking approval process and lead time, minimum top-up, terms on content, support quality. 5+ payment options (wallets and aggregators): merchant documents needed, fees, checkout or API style, settlement time, refund support.

**Step 2.** `docs/research/cost-model.md` and `docs/research/cost-model.csv`: monthly running cost for 10, 50 and 200 institutions with 400 students each. Lines: database and auth, storage and bandwidth, hosting, PDF worker, monitoring, backups, text alerts (three template lengths, stated alerts per student per month), payment fees. Low, base and high cases; every assumption written down.

**Step 3.** Recommendation for D-08 with a fallback, plus an Owner action list with lead times and required documents.

**Step 4.** Requirements for the `alerts` adapter interface (send, status webhook, balance) derived from the shortlisted providers.

**Context for the steps:** Bangla text alerts use Unicode encoding, which fits far fewer characters per segment than English (commonly 70 versus 160, and 67 versus 153 when concatenated). Verify this with each provider, because cost per alert then depends on template length. This task needs web access.
